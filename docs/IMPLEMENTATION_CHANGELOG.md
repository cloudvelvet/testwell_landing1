## 문구와 경로

Hero를 '온라인 검사를 만들고 운영하세요'에서 '검사를 만드는 일부터, 참여와 결과 확인까지'로 바꿨다. 일반 설문보다 심리검사·학습평가 맥락을 명확하게 한다. '검사 만들기'를 '문항 관리에서 시작'으로 구체화하고 질문관리 경로와 로그인 안내를 연결했다. 기존 질문·검사지·그룹·내검사·결과 URL은 바꾸지 않았다. 하단 둘러보기는 공개 메인으로 이동하고 상품이나 가격을 랜딩에 복제하지 않는다.

## 2026-09-08 미팅 전 후속 수정

사용자가 검사 원칙 영역 재검토를 요청해 서브에이전트와 문구를 검토했다. 추상적인 세 항목 나열을 제거하고, 자신감과 지식 확인의 차이를 짧은 예로 든 “이 검사로 무엇을 알고 싶나요?” 안내로 교체했다. MeasurementContext를 App의 독립 섹션에서 WhatIsTestWell의 하위 aside로 옮겼고 별도 배경과 긴 면책 문장을 제거했다. 제품 기능과 일반 조언은 “문항을 준비하기 전에”라는 맥락으로 구분한다. 상세 정의는 내부 문서에 유지한다. 소스: App, WhatIsTestWell, MeasurementContext, content, CSS. 교수님 설명 문서도 갱신했다.

후속 검증: 빌드 및 네 뷰포트 브라우저 검사 통과, React Doctor 100/100. 데스크톱·모바일 전체 캡처를 열어 제작 안내 하단 통합과 줄바꿈을 확인했다. 변경된 기능 경로는 없다.

Hero 버튼을 '검사 만들기'로 바꾸고 안내를 '로그인 후 질문 관리에서 시작하세요.'로 줄였다. 내부 메뉴 용어를 행동 문구로 바꾸며 목적지 /q_bank/question은 유지한다.
