# 랜딩페이지 GO / NO-GO 판단

2026-09-08 / 판정: 조건부 GO. 새로운 서비스나 필수 통과 화면이 아니라 신규 방문자를 위한 공개 안내 입구로 구현한다.

## 직접 확인한 사실

[현재 TestWell](https://testwell.kr/)은 검색, 구매 항목, 내검사·결과 바로가기와 그룹/문제은행 메뉴를 제공한다. [공식 소개](https://testwell.kr/about)는 심리검사·학습평가 분야를 짧게 밝히지만 제작과 참여의 관계를 설명하지 않는다. [로그인 공개 안내](https://testwell.kr/authority/login?next=/)에는 설문 배포와 학습용 문제 설명이 있다. 제작의 의미가 로그인 화면 안에 흩어져 있다. 현재 목록에는 정리 여부가 불명확한 짧은 이름도 있다. 목록 품질을 평가하거나 검사의 타당성을 단정하지 않되 대표 홍보 사례로 복제하지 않는다.

## 일곱 질문

1. 기존 첫 화면: 이미 검사명이나 이용 목적을 아는 사람이 검색·참여·구매·기능 메뉴로 이동하는 서비스 화면.
2. 새 랜딩 역할: 문항과 검사지, 참여·결과의 관계를 이해시키고 목적에 맞는 실제 경로를 선택하게 한다.
3. 역할 구분: 탐색·운영 기능 자체는 기존 서비스, 처음 사용하기 전 의미와 출발점 안내는 랜딩. 검색을 복제하지 않아 구분 가능하다.
4. 없으면 놓치는 것: 검사 제작도 가능한지, 문항 관리에서 시작한다는 사실, 제작자와 참여자의 다른 목적지.
5. 읽은 뒤 행동: 제작자는 질문 관리, 참여자는 내검사, 결과 확인자는 결과 경로. 로그인 필요도 클릭 전에 안내한다.
6. 진입 화면인 이유: 설명만 하고 다시 메뉴를 찾게 하지 않고 해당 경로로 직접 연결한다. 기존 사용자는 헤더에서 본문을 건너뛸 수 있다.
7. 성공 기준: Hero 5초 자가 점검에서 무엇/누구/행동/출발점이 보임, 로그인 게이트까지 두 클릭 이내, 390px 가로 넘침 없음, 모든 제품 문구에 근거 있음. 실제 사용자 실험과 전환율 개선은 아직 검증하지 않았다.

## GO 조건과 경계

목적 설명 부족, 사용자 역할 분리, 기능 진입 전 안내 필요라는 세 조건을 공개 화면에서 확인했다. 기능·일반 원칙 구분과 직접 링크로 과장 없이 해결할 수 있다. 별도 도메인으로 강제 이동시키거나 기존 서비스 전에 반드시 통과시키는 배포는 제안하지 않는다.

향후 실제 서비스 메인이 같은 역할 안내를 충분히 제공한다면 이 내용을 메인에 통합하는 편이 낫다. 클릭 단계가 늘거나 실사용자 이해가 개선되지 않으면 별도 랜딩 운영은 NO-GO로 재평가한다. 예쁜 장식만 남는 경우에도 유지 근거가 없다.

한 문장 목적: 처음 온 사람이 TestWell의 검사 제작·참여 방식을 이해하고 자신의 작업으로 바로 이동하게 한다.
