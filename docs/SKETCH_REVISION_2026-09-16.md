## 메모 누락 정정

응시권 코드 기반 결과확인을 추가했다. 검사하기는 /q_bank/test_cat/{code}, 결과확인은 /q_bank/test_result/{code}로 연결한다. 두 경로는 공식 루트의 공개 스크립트에서 확인했다. 첫 화면 결과 확인은 이 코드 입력을 열고, 상단 메뉴의 결과 확인은 기존 회원용 경로를 유지한다. 실제 응시권 사용 없이 두 제출 목적지를 가로채 검사한다. 교수님 전달 HTML도 _반영본.html로 새로 생성해 이전 파일을 보존한다.
