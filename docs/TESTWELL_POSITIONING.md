# TestWell 포지셔닝

작성일: 2026-09-08. 공개 서비스와 저장소에서 확인한 범위를 기준으로 한 커뮤니케이션 제안이다. 사용자 조사나 제품 성능 비교의 결과가 아니다.

## 최종 정의

**TestWell은 심리검사와 학습평가를 만들고, 참여하고, 결과를 확인하는 온라인 플랫폼입니다.**

서비스 종류는 공식 메인의 심리검사·학습검사 구분, 제작과 관리 범위는 질문·검사지·그룹 메뉴 및 공개 로그인 설명, 참여와 결과 확인은 공개 메인의 실제 링크에 근거한다. 로그인 후 업무 성공이나 모든 검사의 결과 제공 방식을 확인했다는 뜻은 아니다. 상세 검증은 [주장 및 링크 감사](CLAIMS_AND_LINKS_AUDIT.md)를 따른다.

## 한 문장 후보 평가

평가는 편집자의 판단이다. 높음·보통·낮음은 상대적인 전달력이며 실제 사용자 실험의 점수가 아니다. ‘10초’도 낭독 길이 기준의 추정이다.

1. **A:** TestWell은 온라인 검사를 만드는 도구입니다.
2. **B:** TestWell은 문항과 검사지를 준비하는 제작자와 검사에 응답하는 참여자를 연결하는 플랫폼입니다.
3. **C:** TestWell은 문항 관리, 검사지 구성, 그룹 관리와 결과 확인을 지원하는 온라인 검사 서비스입니다.
4. **D:** TestWell은 심리검사와 학습평가를 만들고, 참여하고, 결과를 확인하는 온라인 플랫폼입니다.
5. **E:** TestWell은 설문을 실시하고 학습용 문제의 점수와 결과를 제공하는 온라인 서비스입니다.

| 평가 기준 | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| 비전공자 이해 | 높음 | 높음 | 보통 | 높음 | 높음 |
| 누구를 위한지 | 제작자만 | 양쪽 명시 | 역할 추론 필요 | 동사로 양쪽 제시 | 역할 추론 필요 |
| 할 수 있는 일 | 제작만 | 제작·응답 | 관리 기능 중심 | 제작·참여·결과 | 설문·학습평가 |
| 공개 기능과 일치 | 일치하나 축소 | 일치; 연결은 역할 요약 | 일치 | 일치 | 일치; 점수는 학습용에 한정 |
| 제작자와 참여자 포함 | 낮음 | 높음 | 보통 | 높음 | 보통 |
| 단순 설문 제작기와 구분 | 낮음 | 보통 | 보통 | 높음 | 보통 |
| 쇼핑몰로만 읽힐 위험 | 낮음 | 낮음 | 낮음 | 낮음 | 낮음 |
| 근거 없는 품질 보증 | 없음 | 없음 | 없음 | 없음 | 없음 |
| 10초 이내 구두 설명 | 가능 | 경계 | 경계 | 가능 | 가능 |

**D를 선택한다.** A는 너무 좁고, B는 무엇을 검사하는 서비스인지 빠진다. C는 메뉴를 읽는 느낌이 강하며, E는 심리검사의 맥락이 약하다. D는 제품 범주와 세 가지 행동을 함께 전달한다. 다만 역할 이름은 문장에 없으므로 Hero 부제에서 제작자와 참여자를 명시한다. 경쟁 서비스보다 기능이 우월하다는 비교 문구는 사용하지 않는다.

### 30초

TestWell은 심리검사와 학습평가를 만들고 참여하는 온라인 플랫폼입니다. 제작자는 문항과 검사지를 준비하고 참여자를 그룹으로 관리하며, 참여자는 내 검사와 결과 경로를 이용합니다. 기존 첫 화면은 검색과 상품 목록, 기능 메뉴가 먼저 보여서 처음 온 사람에게 이 구조가 충분히 드러나지 않습니다. 새 랜딩은 그 역할을 먼저 설명하고 각자의 기능으로 바로 연결하는 입구입니다.

### 1분

TestWell은 심리검사와 학습평가를 만들고, 참여하고, 결과를 확인하는 온라인 플랫폼입니다. 공개 서비스에는 질문 관리, 검사지 구성, 그룹 관리와 참여·결과 경로가 있습니다. 그런데 기존 첫 화면에서는 검색과 상품 목록이 눈에 먼저 들어와서 제작 도구도 있다는 점을 놓칠 수 있습니다. 새 랜딩은 기능을 새로 만드는 대신, 처음 온 사람이 서비스의 전체 역할을 이해하도록 돕습니다. 첫 화면에는 제작자가 “검사 만들기” 버튼과 참여자의 내 검사 링크를 두고, 결과 확인은 헤더에서 바로 찾게 했습니다. 기능 관계는 장식 삽화 대신 얇은 선의 도식으로 설명합니다. 문항 준비 안내는 제작 도구 소개 안의 짧은 일반 조언으로 구분합니다. 검사지를 만드는 기능이 개별 검사의 타당성까지 보장하는 것은 아니므로, 확인하지 못한 자동 척도화나 분석 기능은 소개하지 않습니다.

- 분류: 심리검사와 학습평가를 위한 온라인 플랫폼
- 제목: **검사를 만드는 일부터, / 참여와 결과 확인까지.**
- 설명: TestWell은 심리검사와 학습평가를 위한 온라인 플랫폼입니다. 검사 제작·운영자는 문항과 검사지를 준비하고, 참여자는 검사에 응답하고 결과를 확인합니다.
- 제작자 CTA: **검사 만들기** → 공식 질문 관리 `/q_bank/question`
- 보조 CTA: **내 검사 확인** → `/survey/inventory`
- 헤더 결과 확인 → `/survey/my_status`
- 관련 안내: 로그인 후 이용할 수 있습니다.

‘문항 관리’는 이해를 위한 표현이며, 실제 목적지의 메뉴명은 ‘질문 관리’다. 로그인 리디렉션의 next는 확인했으나 로그인 완료 후 실제 도착·업무 수행은 미검증이다. 최종 렌더링 문구는 `src/constants/content.ts`가 기준이다.

## 자주 묻는 질문에 대한 답

### 왜 별도 랜딩페이지를 만들었는가?

기존 공개 메인은 검사 검색, 상품 목록과 기능 메뉴를 제공한다. 새 랜딩의 역할은 신규 방문자에게 ‘무엇을 하는 서비스인지, 나의 역할은 무엇인지, 어디서 시작하는지’를 설명하는 것이다. 검색과 카탈로그를 복제하면 별도 페이지의 의미가 사라진다. 따라서 검색 목록 없이 실제 제작·참여·결과 경로로 직접 연결한다. 이 필요성은 화면 관찰에 근거한 가설이며, 실제 이탈률 개선까지 입증한 것은 아니다.

### 일반 설문 서비스와 무엇이 다른가?

TestWell은 설문뿐 아니라 심리검사와 학습평가라는 사용 맥락을 제공하며, 문항·검사지·그룹과 내 검사·결과 경로를 갖고 있다. 공개 안내에는 그룹 대상 설문과 학습용 문제의 점수·결과 제공이 설명되어 있다. 다만 다른 설문 서비스도 평가 기능을 제공할 수 있으므로 독점적 기능이나 기술적 우위를 주장하지 않는다. 차이는 이 랜딩이 설명하는 사용 목적과 서비스 구조에 있다.

### 누구를 위한 사이트인가?

처음 TestWell을 접한 검사 제작자·운영자와 검사 참여자를 위한 진입 화면이다. 제작·운영 역할에는 연구·교육 등의 상황이 있을 수 있지만 특정 직업만의 제품으로 제한하지 않는다. 기존 이용자에게는 설명을 읽지 않고 내 검사·결과로 갈 수 있는 경로가 중요하다.

### TestWell이 잘하는 것은 무엇인가?

현재 공개 자료로 설명할 수 있는 역할은 문항과 검사지 준비, 그룹 관리, 검사 참여와 결과 확인의 경로를 제공하는 일이다. ‘잘한다’는 표현을 성능 평가로 확대하지 않는다. 속도, 사용성 우위, 진단 정확도나 검사 품질은 이번 확인으로 판단할 수 없다.

## 측정 관련 용어: 내부 설명

아래는 제품 기능 목록이 아니라 용어를 혼동하지 않기 위한 작업 정의다. 특히 ‘척도화’는 분야마다 범위가 달라, 여기서는 관찰 반응을 해석 가능한 척도에 표현하는 뜻으로 사용한다.

| 용어 | 작업 정의 | 혼동하지 않을 것 |
| --- | --- | --- |
| 측정 measurement | 관심 있는 특성을 관찰과 규칙을 통해 표현하고 그 의미를 해석하는 과정 | 단순 숫자 부여만으로 측정의 적절성이 확보되지 않음 |
| 계량화 quantification | 양·정도·빈도 등을 수량으로 표현하는 넓은 작업 | 계량화만으로 심리적 특성의 측정 근거가 생기지 않음 |
| 점수화 scoring | 응답이나 수행에 채점 규칙을 적용하여 점수를 산출하는 작업 | 합산·정오 채점과 척도 구성은 같은 개념이 아님 |
| 척도화 scaling | 반응·수행자료와 특성의 관계를 규칙이나 모형으로 표현하여 해석 가능한 척도상에 배치하는 과정 | 모든 방식이 사람·문항을 동시에 추정하는 것은 아니며, 숫자 코딩이나 합산만을 뜻하지 않음 |
| 표준화 standardization | 실시·채점 절차 등을 일관되게 정하는 과정; 규준 개발은 관련되지만 별도로 명시할 작업 | z점수 변환 하나 또는 타당화 완료를 뜻하지 않음 |
| 타당화 validation | 특정 목적의 점수 해석과 사용을 뒷받침하는 근거를 수집·평가하는 과정 | 검사 전체에 붙이는 영구적인 품질 인증이 아님 |
| 검사개발 test development | 목적·내용 설계, 문항 작성·검토, 시험 실시, 점수·해석 근거 검토와 개선을 포함하는 작업 | 온라인 검사지 작성과 동일하지 않음 |

점수 해석·사용과 근거의 관계, 검사 설계·채점·척도의 구분은 [AERA·APA·NCME 공식 Standards](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf)의 1장, 4장, 5장을 참고했다. 위 표는 원문 정의의 직접 인용이 아니라 이번 문구 검토를 위한 요약이다.

비전공자에게 척도화는 ‘능력이나 태도의 차이를 해석할 수 있는 눈금으로 표현하는 과정’으로 설명할 수 있다. 그러나 이것을 Hero의 판매 문구나 현재 제품의 자동 기능으로 사용하지 않는다. 페이지에서는 “검사의 목적에 맞게 문항을 구성하세요”라는 하위 안내에서 측정하려는 내용에 맞는 문항과 해석 기준을 준비하도록 설명한다.

## 네 가지 층위의 구분

| 층위 | 이 작업에서 다루는 내용 | 표시 방식 |
| --- | --- | --- |
| 현재 공개 기능 | 문항·검사지·그룹, 내 검사·결과 경로; 학습용 점수 안내 | 실제 링크가 있는 기능 설명 |
| 일반적으로 필요한 과정 | 검사 목적, 채점 규칙, 해석 범위와 근거 검토 | ‘검사 결과를 이해할 때’ 등의 일반 안내 |
| 이번 랜딩의 편집 원칙 | 확인된 범위만 설명하고 결과 해석을 과장하지 않음 | 제품 인증이나 공식 기업 철학으로 확장하지 않음 |
| 확인되지 않은 미래 기능 | 자동 척도화, IRT, 신뢰도·타당화 분석, 규준 산출 | 현재 기능에서 제외; 확정 로드맵으로도 표시하지 않음 |

AHA Lab과의 개발·제휴·검증 관계는 확인되지 않았으므로 이름이나 로고를 신뢰 보증에 사용하지 않는다. 계량심리 관점의 전문성은 학술 용어의 양보다 기능과 해석의 범위를 정확히 구분하는 데서 드러나도록 한다.

앞서 기록한 독립 “일반적인 검사 원칙” 섹션과 세 항목, 긴 보증 제외 문구는 화면에서 제거했다. 현재 화면은 제작 안내 안의 작은 aside로 통합했다.

- 라벨: 문항을 준비하기 전에
- 제목: 검사의 목적에 맞게 문항을 구성하세요
