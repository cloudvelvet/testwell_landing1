# TestWell 공개 링크 및 주장 감사

검증일: 2026-09-08. 비로그인 상태의 HTTPS GET 요청으로 응답 코드, Location 헤더, 최종 URL 및 HTML을 확인했다. 요청 시각과 실제 결과는 `artifacts/link-audit.json`에 보존했다. 로그인, 회원가입 제출, 검사 제작·배포·채점·구매는 수행하지 않았다. **최종 200은 로그인 화면의 정상 응답일 수 있으며 기능 검증을 뜻하지 않는다.**

## 측정 원칙 참고

AERA·APA·NCME의 [Standards for Educational and Psychological Testing, 2014 공식 원문](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf), 인쇄본 p.23, Standards 1.0–1.3을 확인했다. 특정 목적의 점수 해석에는 그 해석을 뒷받침하는 근거가 필요하며, 모든 목적·상황에 통용되는 무조건적 타당성 표현은 적절하지 않다는 원칙이다. 이를 “무엇을 알아보는 검사인지, 어떤 기준으로 결과를 해석하는지 함께 확인하세요” 같은 절제된 안내에 반영할 수 있다. 본 참고는 TestWell의 Standards 준수나 개별 검사의 검증 완료를 의미하지 않는다.

## 구현에 적용할 사항

- `links.ts`의 이전 확인일 2026-09-01은 이번 검증일로 갱신할 수 있다.
- CTA는 확인된 서비스 URL로 이동시키며, 로그인 필요 여부를 관련 위치에서 짧게 안내한다.
- `browseTests`의 `/`는 실제 메인이다. 상점 `/shop/sale-goods`와 서로 다른 목적지이므로 버튼 이름에 맞춰 선택한다.
- `#about`, `#features`, `#why`는 로컬 앵커다. 새 랜딩의 실제 section id와 일치하는지는 구현 후 별도 확인한다.
- HTTP 점검과 로그인 뒤의 업무 검증을 구분하고, 결과 페이지의 제공 방식이나 결과 내용을 만들어 보여주지 않는다.
