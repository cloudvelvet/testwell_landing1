# TestWell 공개 링크 및 주장 감사

검증일: 2026-09-08. 비로그인 상태의 HTTPS GET 요청으로 응답 코드, Location 헤더, 최종 URL 및 HTML을 확인했다. 요청 시각과 실제 결과는 `artifacts/link-audit.json`에 보존했다. 로그인, 회원가입 제출, 검사 제작·배포·채점·구매는 수행하지 않았다. **최종 200은 로그인 화면의 정상 응답일 수 있으며 기능 검증을 뜻하지 않는다.**

## 기능과 일반 조언의 경계

MeasurementContext는 WhatIsTestWell 내부 aside이며 라벨은 “문항을 준비하기 전에”다. 목적에 맞는 문항과 해석 기준을 준비하라는 일반 조언이고, 제품의 분석·검증 능력을 주장하지 않는다. 자동 척도화·IRT·진단 정확도·품질 인증·AHA Lab의 개발 또는 검증 관계는 기능 문구에 없다.

[AERA·APA·NCME 공식 Standards 원문](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf)의 점수 해석과 사용 목적에 대한 근거 원칙을 내부 문구 검토에 참고했다. TestWell의 표준 준수나 개별 검사 검증 완료를 뜻하지 않는다.

## 배포 범위

현재 CTA 목적지는 로컬에서 확인한 기존 공식 서비스다. 루트 배포 후 검사 목록·응시권 코드·next=/의 도착·회사 정보·서버 통합은 미결이다. [루트 배포 차단 항목](DEPLOYMENT_BLOCKERS.md)이 해소될 때까지 운영 루트 배포는 차단한다. 기존 HTTP 감사 원본은 artifacts/link-audit.json에 보존하고 이번 CTA 재검사는 route-checks.json으로 구분한다.

## 배포 전 최종 문구 기준

- 버튼 안내: 로그인 후 질문 관리에서 시작하세요.

- 문항 준비 안내 제목: 이 검사로 무엇을 알고 싶나요?
- 문항 준비 안내 본문: 태도나 경험을 묻는 문항과 지식이나 수행을 확인하는 문제는 측정하려는 내용과 결과 해석 방식이 다릅니다. 먼저 무엇을 알아보려는지 정하고, 목적에 맞는 문항과 해석 기준을 준비하세요.
