## 두 버전 비교

- 다크 버전에서 보존: 검정·노랑 대비, 큰 왼쪽 정렬 제목, 제작자/참여자 분리, 실제 목적지 안내, 검증되지 않은 분석 주장을 피한 점, 짧은 페이지.
- 검색 대안에서 참고: 밝은 면으로 정보 위계 만들기, 실제 서비스 링크 중심, 전역 reduced motion. 검색 기능과 카탈로그 자체는 가져오지 않는다.
- 양쪽에서 버림: 반복 CTA, 분위기만 위한 대형 삽화, 오래된 정적 검사 목록, 상수와 내부 문자열 중복, 근거 없는 제품 화면.
- 실제 서비스와 불일치 위험: 임의 단계가 반드시 필요한 절차처럼 보이는 도식, 자동 분석/진단/척도화 능력 추론. 메뉴 관계로만 한정한다.
- 디자인은 좋지만 목적에 맞지 않음: 긴 다크 Hero는 화면의 분위기는 잡지만 문항과 검사 운영을 설명하는 근거가 되지 않는다.

14가지 질문에 대한 결론: 무엇과 제작자 대상은 부분 충족, 참여자 경로와 제작 출발점은 장점. 제품 이해와 시각 리듬·모바일 진입·반복 감소가 우선 개선 대상이다. 별도 랜딩의 존재 이유는 역할 안내에 있으며, 연구실/AI/쇼핑몰 외형을 만드는 것이 아니다. 로그인 후 수행 기능은 미확인이므로 공개 설명보다 구체적인 조작 주장은 추가하지 않는다.
