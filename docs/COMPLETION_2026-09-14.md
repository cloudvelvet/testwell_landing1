# 랜딩페이지 마무리 기록

대상: `codex/landing-v3-reference-led`, 시작 커밋 `c328d54`.

확정된 검정·크림 디자인, 네 가지 바로가기, 여섯 원형 기능 안내, 본문과 서비스 목적지를 기준으로 마무리했다.

## 반영 사항

- 응시권의 빈 값·공백 입력 오류를 입력란 아래에 표시하고 `aria-invalid`와 오류 설명을 연결했다.
- `.` / `..`가 URL의 상위 경로로 해석되는 이동을 막았다. 그 밖의 코드는 앞뒤 공백을 제거하고 단일 경로 조각으로 인코딩한다. 실제 유효 여부는 공식 서비스에서 판단한다.
- Esc로 응시권 폼을 닫으면 원래 버튼으로 포커스가 돌아간다. 펼침 상태는 화살표 방향으로도 표시한다.
- 1024–1199px에서 원형 안내의 내부 여백을 조정했다.
- Pretendard 1.3.9 가변 폰트를 자체 제공하고 원본 라이선스를 배포 산출물에 포함했다. 외부 폰트 서버 요청이 없어졌다.
- Vite 자산과 favicon을 상대 경로로 제공하도록 수정했다.
- Playwright를 개발 의존성으로 명시했다. `npm run check`는 빌드·미리보기·브라우저 검사·현재 소스 정합성 확인을 수행하고 서버를 종료한다.
- 과거 특정 커밋과 특정 브라우저 설치에 의존하던 검증을 현재 소스와 실제 동작 검증으로 갱신했다. 과거 `artifacts/`는 기록으로 보존하고 새 결과는 `output/verification/`에 생성한다.

## 확인 결과

Node 24.19.0, Playwright 1.62.1, Chromium 153에서 프로덕션 빌드를 실행해 검사했다. 이 환경에서는 표준 Chromium 다운로드가 실패해 npm으로 받은 Chromium 실행 파일을 `PLAYWRIGHT_EXECUTABLE_PATH`로 지정했다.

- TypeScript 및 Vite 프로덕션 빌드: 통과.
- 화면 폭 320·360·390·768·1024·1280·1440px: 통과.
- 한국어 폰트 실제 로드, 단일 h1, 제목 단계, 링크 목적지·앵커, 가로 넘침, 원형 비율: 통과.
- 모바일 메뉴의 키보드·Esc·외부 클릭·화면 크기 변경·포커스 이탈: 통과.
- 응시권 빈 값·공백·점 경로 차단, 오류 해제, Esc 복귀, 특수문자와 한글 코드 인코딩: 통과.
- 본문 건너뛰기, 포커스 표시, 설정된 텍스트 색 대비: 통과.
- 브라우저 콘솔 오류: 없음.
- 1440·1024·320px 전체 화면 캡처를 직접 확인했다.

응시권 제출은 브라우저 테스트에서 요청을 가로채 목적지만 확인했다. 실제 응시권 사용, 로그인 제출, 인증 후 결과 조회는 수행하지 않았다. 전체 WCAG 적합성이나 실제 사용자 평가를 뜻하지 않는다.

## 운영 연결 범위

랜딩 프런트엔드 수정은 완료했다. 이 저장소에는 운영 서비스 백엔드·서버 설정이 없으므로 `testwell.kr` 메인을 교체하거나 서비스 기능을 배포하지 않았다. 현재 검사 보기 링크가 공식 루트이므로 동일 루트 교체에는 검사 목록의 새 주소와 기존 기능 보존 확인이 필요하다. 상세 조건은 `docs/DEPLOYMENT_BLOCKERS.md`를 따른다.
