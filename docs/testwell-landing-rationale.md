# TestWell 랜딩 문구 근거

TestWell은 심리검사와 학습평가를 만들고, 참여하고, 결과를 확인하는 온라인 플랫폼이다. 기존 서비스의 검색·기능을 재구현하지 않고 신규 방문자가 제작/참여의 목적에 맞게 실제 메뉴로 이동하게 한다.

- 필요성 판단: [GO / NO-GO](LANDING_GO_NO_GO.md)
- 후보와 최종 문구: [포지셔닝](TESTWELL_POSITIONING.md)
- 링크와 주장: [감사](CLAIMS_AND_LINKS_AUDIT.md)
- 시각 결정: [V3](DESIGN_V3.md)

질문·검사지·그룹 메뉴와 공식 로그인 공개 설명을 기능 근거로 사용한다. 자동 분석, 품질 보증, AHA Lab 관계는 추론하지 않는다. 점수 해석의 기준은 일반적인 검사 원칙으로 구분한다. 교수님 설명은 [요약 문서](PROFESSOR_BRIEF.md)에 있다.
