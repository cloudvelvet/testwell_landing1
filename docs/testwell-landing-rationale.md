# TestWell 랜딩페이지 메시지 구성 근거

## 한 문장 정의

TestWell은 온라인 검사를 만들고, 참여하고, 결과를 확인하는 서비스다.

## 정보 순서

1. 첫 화면에서 서비스가 하는 일을 한 문장으로 설명한다.
2. 같은 첫 화면에 제작 버튼과 참여자의 내검사·결과 확인 링크를 둔다.
3. 첫 설명에 설문·학습평가라는 사용 상황을 제시하고, 기능 목록은 질문·검사지·참여자라는 관리 대상으로 통일한다. 검증되지 않은 필수 절차로 보이지 않도록 번호를 붙이지 않는다.
4. 같은 섹션 아래 일반적인 검사 설명을 작게 배치해 척도화와 점수 해석의 근거를 구분한다. '검사 이해를 위한 참고 설명' 라벨로 기능 안내와 구분하고 제품 자동 분석 능력을 주장하지 않는다.
5. 헤더·히어로·하단의 강조 버튼은 질문 관리로 연결한다. 히어로 버튼에는 시작 화면과 로그인 필요 안내를 연결하고 마지막에는 질문 작성부터 시작하도록 안내한다.

## 표현 원칙

- 계량심리, 타당화 같은 전문 용어를 첫 화면에 앞세우지 않는다.
- 랜딩페이지 제작자가 서비스를 직접 개발한 것처럼 말하지 않는다.
- 심리·교육·조직 등 특정 분야로 사용 범위를 제한하지 않는다.
- 공개 서비스에서 확인하지 않은 성능, 점수 산출, 연구 효과를 주장하지 않는다.
- 가짜 제품 화면이나 임의의 수치를 사용하지 않는다.

## 시각 방향

검정·노랑·크림의 대비를 유지한다. 히어로의 크림색 면은 참여자 바로가기에 사용한다. 답안지 모티프와 역할 선택 카드는 제거해 설명과 클릭 목적지가 명확하도록 했다.

## 교수님께 설명할 때

“참여자는 바로 검사와 결과를 찾고, 운영자는 어떤 일에 쓸 수 있는지 알도록 구성했습니다. 척도화와 점수 해석은 짧은 일반 설명으로 남기되, TestWell에서 확인한 기능과 구분했습니다. 랜딩페이지가 검사의 품질이나 자동 분석을 보장하는 것처럼 읽히지 않도록 했습니다.”

## 근거와 확인 범위

- 설문을 그룹에 실시하고 학습용 문제를 만들어 채점·결과를 제공한다는 내용은 공식 공개 안내 https://testwell.kr/authority/login 에 근거한다.
- 결과 해석·사용의 근거에 관한 참고: https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf
- AHA 연구 분야를 제품 기능으로 옮기지 않았다.
- 사용자 요청에 따라 로그인 후 실제 채점·척도 설정 확인은 이번 수정에서 제외했다. 자동 채점 방식·개별 보고서·자동 척도화·타당화는 확인하지 않았으며 기능으로 주장하지 않는다.
