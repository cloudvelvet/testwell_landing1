# TestWell 참고 사이트 검토 및 반영 — 2026-09-07

## 판단
이전 화면은 검사 찾기·결과 보기 버튼을 반복했고, 검사 제작을 이해한 사람이 설계했다는 근거가 약했다. 이번 수정은 제작의 구조, 측정에 대한 질문, 실제 메뉴로 이어지는 동선을 보여주는 데 집중한다.

## 공식 참고 자료
- formr: https://formr.org/ 및 https://formr.org/documentation — 기능을 구체적인 연구·운영 작업으로 설명한다. TestWell에는 작업별 관리 화면을 명확히 연결하는 방식을 반영했다.
- jsPsych: https://www.jspsych.org/latest/ — 도구의 범위와 실제 시작 경로를 구체적으로 제시한다. TestWell에 없는 실험 기능이나 정밀도 주장은 가져오지 않았다.
- PsyToolkit: https://www.psytoolkit.org/survey-library/ — 척도별 설명과 배경·참고문헌, 체험 경로를 구분한다. 근거를 직접 읽을 수 있는 연결과 이용 목적별 안내를 참고했다.
- TestWell: https://testwell.kr/about — 심리검사·학습평가 서비스 소개와 공개 메뉴만 제품 기능의 근거로 사용한다.
- Testing Standards: https://www.testingstandards.net/open-access-files.html — AERA·APA·NCME가 함께 발행한 검사 기준의 공개 자료로 연결한다. TestWell 인증이나 기준 충족의 증거로 쓰지 않는다.

## 반영 내용
1. 히어로의 중복 참여 안내를 문항·검사지·그룹 관리 구조로 교체했다. 문항 그림은 설명용 도식으로 표시한다.
2. 측정 개념, 문항의 적절성, 점수 해석 범위라는 세 질문을 검사 설계 관점으로 소개한다.
3. 상단 탐색을 이용 안내·측정의 관점·문제은행으로 바꿔 페이지의 설명과 제품으로 연결한다.
4. 실제 연구 결과, 신뢰도·타당도 수치, 검증된 척도, 학위·소속 보증은 추가하지 않았다. 계량심리 공부 배경은 사용자 제공 맥락이다.

## 추후 실제 자료로 보완할 부분
검사별 개발 목적·대상·문항 예시·해석 근거·참고문헌을 갖춘 실제 사례가 있으면 연구자의 전문성을 훨씬 구체적으로 보여줄 수 있다. 현재 시안에 임의의 검사 결과나 검증 수치를 만들지 않는다.

## 후속 문체 조정
사용자 피드백에 따라 학술적 선언이 강한 측정 관점 섹션과 기준 링크를 제거했다. 화면은 서비스 기능, 목적별 메뉴, 제작 도식에 집중하며 제목 크기와 하단 여백도 줄였다. 위 참고 자료 검토는 디자인 작업 기록이다.
